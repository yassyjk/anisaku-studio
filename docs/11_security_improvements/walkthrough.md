# 修正内容の確認 (Walkthrough)

## 修正の概要

セキュリティ向上のため、通信制限、入力検証、リソース制限の3つの対策を実施しました。

## 修正の詳細

### 1. Originチェック

- バックエンドの `main.go` および `handlers/websocket.go` で `ALLOWED_ORIGINS` 環境変数を参照するようにしました。
- 開発環境（localhost/127.0.0.1）は自動的に許可されるため、開発効率を損なうことはありません。
- 本番環境では環境変数で `ALLOWED_ORIGINS=https://your-domain.com` のように指定することで、外部ドメインからの不正なアクセスを防ぎます。

### 2. 入力値の検証

- プレイヤー名の最大長さを **15文字** に制限しました。
- フロントエンド: `input` タグに `maxLength={15}` を設定し、送信処理直前にも切り詰め処理を入れることで二重にガードしています。
- バックエンド: 受信した `join` メッセージ内の名前を検証し、15文字を超える場合は自動的に切り詰めます。また、空文字の場合は "Guest" をデフォルト値とします。

### 3. リソース制限 (DoS対策)

- **ルーム数制限**: サーバー全体で同時に存在できるルーム数を **最大100** に制限しました。上限に達した際は `503 Service Unavailable` を返し、サーバーのメモリ枯渇を防ぎます。
- **データサイズ制限**: WebSocketのバッファサイズを `1024` バイトに明示的に設定しました。これにより、巨大なパケットを送りつける攻撃によるリソース消費を抑制します。

## 動作確認方法 (提示)

リモートCIで以下のテストが通ることを確認してください。

- バックエンド: `go test ./handlers/...`
- フロントエンド: `npm run test`

また、手動で以下の環境変数を設定してサーバーを起動し、指定外のドメインからアクセスできないことを確認してください。

```bash
ALLOWED_ORIGINS=http://localhost:5173
```
