# 実装計画: プレイヤーの順番入れ替え機能

ゲームの順番が接続順になっている現状を改善し、ホストがロビー画面でプレイヤーの順番を自由に入れ替えられるようにします。

## 変更内容

### バックエンド (`backend/handlers/websocket.go`)

- `Message` の種類に `reorder_players` を追加します。
- `reorder_players` メッセージを受け取った際、ペイロードに含まれるプレイヤー ID の配列に従って `GameState.Players` を並び替えます。
- 並び替え後、全員に最新の状態を `broadcast` します。

### フロントエンド (`frontend/src/App.tsx`)

- ロビー画面のプレイヤーリストにおいて、自分がホストの場合のみ各プレイヤーの横に「↑」と「↓」ボタンを表示します。
- ボタンが押された際、ローカルのリストを入れ替えた後、新しい順序（IDの配列）をサーバーへ `reorder_players` メッセージとして送信します。
- デザインは既存のスタイルに合わせ、直感的に操作できるようにします。

## 検証計画

### 自動テスト

- [ ] バックエンドのユニットテストで、`reorder_players` メッセージによってプレイヤーリストが正しく更新されることを確認します。

### 手動検証

- [ ] 2人以上で入室し、ホスト画面で順番を入れ替える。
- [ ] 非ホスト画面でも順番がリアルタイムに更新されることを確認する。
- [ ] 入れ替えた順番の通りにゲーム（ターン）が進行することを確認する。
