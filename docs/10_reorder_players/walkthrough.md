# 修正内容の確認 (Walkthrough)

ホストがロビー画面でプレイヤーの順番を入れ替えられる機能を実装しました。

## 変更内容

### バックエンド

- `reorder_players` メッセージのハンドラを追加しました。
- 受信したプレイヤーIDのリストに基づいて `GameState.Players` を並び替えるロジックを実装しました。

### フロントエンド

- ロビー画面のプレイヤーリストに、ホスト限定で「▲」「▼」ボタンを表示するようにしました。
- ボタンクリック時に `handleReorder` 関数を実行し、新しい順序をサーバーへ送信するようにしました。

## 検証結果

### 動作確認

- [x] ホスト画面で「▲」「▼」ボタンが表示されること。
- [x] ボタンを押すとプレイヤーの順序が入れ替わり、サーバーへ通知されること。
- [x] 入れ替わった順序が全クライアントに同期されること。
- [x] 入れ替えた後の順序でゲームが開始されること（ターンの順番が新しいリストに従うこと）。

## 実行コマンド

ローカル環境で動作を確認するには、以下のコマンドでサーバーとフロントエンドを起動してください。

```bash
# Backend
cd backend && go run main.go

# Frontend
cd frontend && npm run dev
```
