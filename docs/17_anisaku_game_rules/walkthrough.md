# 実装内容

- アプリ名・PWA名を「アニ作」に変更。
- 脚本、作画、声優、音楽それぞれに同じ16種類のタグ構成を割り当て、64枚の山札を生成。
- 初期状態を手札4枚・コイン5枚とし、手番をカード取得と解決の2段階で管理。
- 捨て札購入時に1コインを持ち主へ移し、手札情報は本人以外に配信しない。
- 公開作品を作品一覧に記録し、タグ重複点を計算。2作品目の公開と同時にコインを含めて順位を確定。
- フロントエンドにカード選択、購入、公開、捨て札、順位表示を追加。
- 詳細ルールを `rule.md` に記録。

## 使用技術

既存のSolidJS、Go、Gin、WebSocket、HTTP pollingを継続利用しました。ゲーム状態の権威をサーバー側に置き、ブラウザー間でルール判定がずれないようにするためです。新たな外部ライブラリは追加していません。
