# アニ作ゲームルール実装タスク

## 目的

汎用ターン制ゲームを「アニ作」の公式ルールに置き換え、2〜8人でカード取得・作品公開・得点集計を行えるようにする。

## 対応内容

- 4要素各16枚、合計64枚のタグ付きカードを生成する。
- 初期手札4枚、コイン5枚、山札/捨て札を管理する。
- 山札からの取得と、他プレイヤーの直前の捨て札を1コインで購入する処理を実装する。
- 手札から4要素を揃えて公開するか、1枚捨てる手番処理を実装する。
- タグ重複得点と、2作品目公開時の即時終了・最終順位を実装する。
- 他プレイヤーの手札を通信状態から隠し、画面・ルール文書・PWA名を「アニ作」に揃える。

## 完了条件

- ゲームの状態遷移が提示ルールと一致する。
- 手札秘匿、カード構成、得点、ゲーム終了条件を自動テストで確認できる。
- フロントエンドがスマートフォン幅で操作でき、結果にトップ/ロビーの戻り先がある。
