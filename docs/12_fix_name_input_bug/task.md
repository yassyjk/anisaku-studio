# タスク: 名前入力バグの修正とエラー表示の追加

## 現状の課題

1.  **日本語入力バグ**: 日本語で名前を入力しようとすると、4文字以上入力できない（入力が途切れる）。
    - 原因: バックエンドで `len()`（バイト長）を使用しているため、日本語1文字（3バイト）× 4文字 = 12バイトとなり、10バイト制限に引っかかる。
    - 原因: フロントエンドで `onInput` 時に強制的に値を書き換えているため、IME（日本語入力）の確定前の状態が壊れる。
2.  **エラー表示の不足**: 10文字を超えた場合にユーザーに理由（制限）を伝えるメッセージが表示されていない。

## 解決策

- バックエンドをバイト数制限から「文字数制限」に変更する。
- フロントエンドの入力処理をIME（日本語入力）に対応させる。
- 10文字を超えた際に「10文字までです」というエラーメッセージを表示する。
