# 実装計画: 名前入力バグの修正とエラー表示

## 1. バックエンドの修正 (`backend/handlers/websocket.go`)

- `len(p.Name)` を使用している箇所を、マルチバイト文字を正しくカウントできる `utf8.RuneCountInString(p.Name)` に変更する。
- これにより、日本語でも10文字まで入力可能にする。

## 2. フロントエンドの修正 (`frontend/src/App.tsx`)

- `nameError` という新しいシグナルを追加し、エラーメッセージを管理する。
- `onInput` ハンドラを修正:
    - 値の長さが10文字を超えた場合に `nameError` をセットする。
    - 入力中の値を強制的に切り詰める（`substring` する）処理を削除し、IMEの状態を壊さないようにする。
- `isComposing` というフラグを用意し、IME入力中（`onCompositionStart` ～ `onCompositionEnd`）は通信を発生させないように制御する。
- 入力欄の下に、エラーがある場合に「10文字までです」と赤字で表示する。

## 3. フロントエンドの補助修正 (`frontend/src/websocket.ts`)

- `connectWs` 内の `join` メッセージ送信時も、10文字で切り詰める際に文字数ベース（`substring`）で処理が行われていることを再確認（既に修正済みだが、念のため整合性を確認）。

## 検証プラン

- 日本語で「あいうえお、かきくけこ」と入力して、正しく10文字入ることを確認。
- 11文字以上を入力しようとした際（または入力後）に「10文字までです」と表示されることを確認。
- バックエンド側でも正しく10文字制限がかかることを確認。
