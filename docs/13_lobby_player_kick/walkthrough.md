# 修正内容の確認 (Walkthrough) - ロビーでのプレイヤー削除機能

ロビー画面でホストが他のプレイヤーを削除（キック）できる機能を実装しました。

## 変更内容

### バックエンド
- **[websocket.go](file:///home/yasuni/デスクトップ/makes/game-template/backend/handlers/websocket.go)**:
    - `kick_player` メッセージのハンドラを追加しました。
    - ホスト権限のチェックと、自分自身を除外できないガードを実装しました。
    - 除外されたプレイヤーへの個別通知（`kicked` メッセージ）と、他プレイヤーへの状態更新（`broadcast`）を実装しました。

### フロントエンド
- **[websocket.ts](file:///home/yasuni/デスクトップ/makes/game-template/frontend/src/websocket.ts)**:
    - サーバーからの `kicked` メッセージを受け取った際に、アラートを表示してトップ画面へリダイレクトする処理を追加しました。
- **[App.tsx](file:///home/yasuni/デスクトップ/makes/game-template/frontend/src/App.tsx)**:
    - `handleKick` 関数を追加し、確認ダイアログを表示してからサーバーに要求を送るようにしました。
    - ロビー画面のプレイヤーリストに、ホストのみ、かつ自分以外の場合に表示される削除ボタン（✕）を追加しました。

## 検証結果

### 手動確認手順
1. ホストとしてルームを作成。
2. 別の端末またはブラウザタブからゲストとして参加。
3. ホスト側の画面で、ゲストの横に削除ボタン（赤い✕）が表示されていることを確認。
4. ホスト自身の横にはボタンが表示されていないことを確認。
5. ボタンをクリックし、確認ダイアログで「OK」を選択。
6. ゲスト側の画面で「ホストによってルームから退出させられました。」という通知が表示され、トップ画面に戻ることを確認。
7. ホスト側の画面でもプレイヤーリストからゲストが消えることを確認。
