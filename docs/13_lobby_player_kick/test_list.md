# テストリスト - ロビーでのプレイヤー削除機能

機能が正しく動作するか、以下のケースを確認します。

## 正常系 (Success Cases)
- [ ] **ホストによるプレイヤーの削除**:
    - ホストが他のプレイヤーの横にある削除ボタンを押すと、そのプレイヤーがルームから除外される。
    - 除外されたプレイヤーの画面がトップ画面に切り替わり、通知が表示される。
    - 残っている他のプレイヤーの画面でも、リストから除外されたプレイヤーが消える。

## 異常系 / エッジケース (Error/Edge Cases)
- [ ] **自分自身の削除不可**:
    - ホスト自身の横には削除ボタンが表示されない。
    - (APIを直接叩いたとしても) サーバー側で自分自身のキック要求を拒否する。
- [ ] **非ホストによる削除不可**:
    - ホスト以外のプレイヤーの画面には、他人の横に削除ボタンが表示されない。
    - (APIを直接叩いたとしても) サーバー側でホスト以外のキック要求を拒否する。
- [ ] **存在しないプレイヤーの削除**:
    - すでに退出したプレイヤーなどをキックしようとしても、エラーにならず安全に処理される。

## テスト実行手順 (リモートCI用)
テストはリモートのCI環境で実行されます。ローカルでテストコードを追加した場合は、プッシュ（今回はコミット）後にCIの結果を確認してください。
実行コマンド（参考）:
- バックエンド: `go test ./backend/...`
- フロントエンド: `npm test` (frontendディレクトリ内)
