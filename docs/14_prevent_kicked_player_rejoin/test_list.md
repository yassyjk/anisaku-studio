# テストリスト - キックされたプレイヤーの再参加防止

## 正常系 (Success Cases)
- [ ] **キック後の再参加ブロック**:
    - ホストにキックされた後、同じタブで再度同じ部屋に参加しようとすると、ブロックされる。
- [ ] **別の部屋への参加**:
    - 部屋Aでキックされても、別の部屋Bには正常に参加できる。
- [ ] **セッションリセット後の再参加**:
    - タブを一度閉じ、再度開き直した（セッションがリセットされた）後は、キックされた部屋にも再度参加できる。

## 異常系 / エッジケース (Error/Edge Cases)
- [ ] **手動での部屋ID入力**:
    - URLパラメータ経由だけでなく、トップ画面の入力欄から部屋IDを手入力した場合も正しくブロックされる。
- [ ] **再接続時の挙動**:
    - キックされていない通常の切断・再接続時は、制限に掛からずスムーズに参加できる。
