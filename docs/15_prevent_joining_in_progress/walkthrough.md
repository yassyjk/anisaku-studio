# 修正内容の確認 (Walkthrough) - ゲーム進行中の新規参加制限

ゲームが開始された後に、新規のプレイヤーがルームに参加できてしまうバグを修正しました。

## 変更内容

### バックエンド
- **[websocket.go](file:///home/yasuni/デスクトップ/makes/game-template/backend/handlers/websocket.go)**:
    - `join` メッセージの処理において、フェーズのチェックを追加しました。
    - フェーズが `lobby` 以外（`playing` や `result`）の場合、既存のプレイヤーリストに存在しない新規プレイヤーの参加要求を拒否するようにしました。
    - 拒否されたプレイヤーには、「ゲームが進行中のため参加できません」というエラーメッセージを返します。

## 検証結果

### 手動確認
1. **ロビー中の参加**: ゲーム開始前は、新しいプレイヤーが正常に参加できることを確認。
2. **進行中の新規参加ブロック**: ゲーム開始後（`playing` フェーズ）に、新しいブラウザタブから同じルームIDで参加を試みた際、「ゲームが進行中のため参加できません」というアラートが表示され、参加が阻止されることを確認。
3. **進行中の既存プレイヤー復帰**: ゲーム開始前に参加していたプレイヤーが、ページをリロードして再接続した場合、正常にゲームに復帰できることを確認。
