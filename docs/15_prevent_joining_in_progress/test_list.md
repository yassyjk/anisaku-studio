# テストリスト - ゲーム進行中の新規参加制限

## 正常系 (Success Cases)
- [ ] **ロビー中の新規参加**:
    - フェーズが `lobby` の間は、新しいプレイヤーが正常に参加できる。
- [ ] **進行中の既存プレイヤー再接続**:
    - フェーズが `playing` または `result` の時、すでにリストにいるプレイヤーが再接続（リロード等）した場合は正常に復帰できる。

## 異常系 / エッジケース (Error/Edge Cases)
- [ ] **進行中の新規参加ブロック**:
    - フェーズが `playing` の時に、リストにいない新しいプレイヤーが参加しようとすると、「ゲームが進行中のため参加できません」というエラーが表示され、拒否される。
- [ ] **終了後の新規参加ブロック**:
    - フェーズが `result` の時に、新しいプレイヤーが参加しようとした場合も同様に拒否される。
