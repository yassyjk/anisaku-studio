# 実装計画 - ゲーム進行中の新規参加制限

ゲームが開始された（`playing` フェーズ等）後に、初期メンバー以外のプレイヤーがルームに参加できてしまう問題を修正します。

## ユーザーレビューが必要な項目
- 既存のプレイヤーが一度切断して再接続するケースは、引き続き許可する必要があります（リストにすでにIDが存在する場合）。
- 拒否されたプレイヤーには「ゲームが進行中のため参加できません」というエラーメッセージを表示します。

## 変更内容

### [Backend] ゲームサーバーロジックの修正

#### [MODIFY] [websocket.go](file:///home/yasuni/デスクトップ/makes/game-template/backend/handlers/websocket.go)
- `join` メッセージの処理において、以下の条件をチェックするように変更します。
    - ルームのフェーズが `lobby` ではない場合。
    - かつ、送信されたプレイヤーIDが既存のプレイヤーリスト（`state.Players`）に含まれていない場合。
- 上記の条件に合致する場合、参加を拒否し、`error` メッセージをクライアントに送信して処理を終了します。

## 検証計画

### 手動確認
1. ブラウザAでホストとしてルームを作成。
2. ブラウザBでプレイヤーとして参加。
3. ホスト（A）がゲームを開始する（`playing` フェーズへ）。
4. 新しくブラウザCを開き、同じルームIDで参加を試みる。
5. ブラウザCに「ゲームが進行中のため参加できません」というアラートが表示され、トップ画面に戻されることを確認。
6. ブラウザBをリロード（再接続）し、正常にゲームに復帰できることを確認。
